# Reproducibility verification

## Procedure

Scripts 01-10 and the environment check were executed sequentially
in a separate working directory.

The saved Kang18_8vs8 input was copied into that directory.
Processed files and analysis results were regenerated by the scripts.

All analysis scripts completed successfully.

## Comparisons

The following comparisons passed:
- Starting dataset MD5 fingerprint.
- All CSV tables generated under results/tables by the rerun.
- Raw counts in the primary and eight LODO model objects.
- Model sample metadata and design formulas.
- Normalization size factors and dispersion estimates.
- Primary and LODO DESeq2 result tables.

Numeric comparisons used an all.equal tolerance of 1e-8.
The detailed checks are recorded in reproducibility_comparison.csv.

## Scope and limitations

This verifies reproducibility from the same saved input in the
current R/package environment.

It does not verify a fresh download, installation in a clean
environment, or identical behavior across software versions.

Figure files were not compared byte-for-byte.
Additional descriptive tables created interactively were outside
the numbered-script rerun.

Reproducibility of computation is distinct from biological validation.

## Commands

Run from the project root:

    Rscript scripts/check_environment.R
    python3 scripts/run_repro_check.py
    Rscript scripts/compare_repro_results.R

The Python runner uses the standard library and invokes Rscript.
It creates a timestamped directory under repro_checks and stops
if an analysis script fails.
